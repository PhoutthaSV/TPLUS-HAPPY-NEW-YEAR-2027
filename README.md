# TPLUS Lucky Draw – Happy New Year 2027

## ເລີ່ມໃຊ້ງານ
1. ຕິດຕັ້ງ Node.js (ມີແລ້ວໃນເຄື່ອງນີ້)
2. ກົດ `start.bat` ສອງເທື່ອ (ຫຼື `node server.js`) → ເປີດ http://localhost:3000
3. ຄອມ ແລະ ໂທລະສັບຂອງຜູ້ເຂົ້າຮ່ວມ ຕ້ອງຢູ່ Wi-Fi ດຽວກັນ ເພື່ອສະແກນ QR ລົງທະບຽນ
4. ຕ້ອງມີອິນເຕີເນັດ (ໂຫຼດ Tailwind / ຟອນ / QR library ຈາກ CDN)

## ໄຟລ໌
- `List.csv` – ລາຍຊື່ພະນັກງານ. ແກ້ໄຂໃນ Excel ແລ້ວ Save → ວົງລໍ້ອັບເດດເອງພາຍໃນ 3 ວິນາທີ
  (ຖ້າມີ `List.xlsx` ທີ່ໃໝ່ກວ່າ ຈະໃຊ້ໄຟລ໌ນັ້ນແທນ)
- `data/state.json` – ລາງວັນ, ຜົນການຈັບ, ຜູ້ລົງທະບຽນ (ລຶບໄຟລ໌ນີ້ = ເລີ່ມໃໝ່ທັງໝົດ)
- ຟອມລົງທະບຽນ: http://<IP ເຄື່ອງ>:3000/register

## ລາຍຊື່ພະນັກງານ
`List.csv` ບໍ່ໄດ້ຢູ່ໃນ GitHub (ຂໍ້ມູນສ່ວນຕົວ). ກັອບປີ້ `List.example.csv` ເປັນ `List.csv` ແລ້ວໃສ່ລາຍຊື່ແທ້.

## ໃຫ້ສະແກນ QR ໄດ້ຜ່ານອິນເຕີເນັດ (4G/5G, ບໍ່ຕ້ອງຢູ່ Wi-Fi ດຽວກັນ)
1. ຕິດຕັ້ງ cloudflared ເທື່ອດຽວ (ເປີດ PowerShell):
   `winget install --id Cloudflare.cloudflared`
2. ກົດ `start-online.bat` ແທນ `start.bat`
3. ລໍຖ້າ 5–10 ວິນາທີ — ແຖບ ⭐ ຈະຂຶ້ນ "🌐 Online ພ້ອມແລ້ວ" ແລະ QR ຈະປ່ຽນເປັນລິ້ງ `https://xxxx.trycloudflare.com/register` ເອງ
4. ຄອມຕ້ອງເປີດ ແລະ ມີອິນເຕີເນັດຕະຫຼອດງານ. ລິ້ງຈະປ່ຽນໃໝ່ທຸກເທື່ອທີ່ເປີດ — ໃຫ້ສະແດງ QR ຈາກໜ້າຈໍງານເທົ່ານັ້ນ (ຢ່າພິມ QR ໄວ້ລ່ວງໜ້າ)

ຄວາມປອດໄພ: ຄົນທີ່ເຂົ້າຜ່ານລິ້ງ Online ເປີດໄດ້ສະເພາະຟອມລົງທະບຽນ. ໜ້າວົງລໍ້ ແລະ ຂໍ້ມູນ admin ເປີດໄດ້ສະເພາະຄອມນີ້ ແລະ Wi-Fi ດຽວກັນ.
ການດຶງຊື່ອັດຕະໂນມັດຈາກລະຫັດພະນັກງານ ຖືກປິດສຳລັບຜູ້ເຂົ້າຜ່ານ Online (ກັນຄົນນອກເບິ່ງລາຍຊື່).

ໃຊ້ ngrok ຫຼື ລິ້ງອື່ນ: ວາງລິ້ງໃນຊ່ອງ "ວາງລິ້ງເອງ" ໃນແຖບ ⭐ ແລ້ວກົດ "ໃຊ້".
