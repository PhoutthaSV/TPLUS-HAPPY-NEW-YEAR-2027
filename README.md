# TPLUS Lucky Draw – Happy New Year 2027

## ເລີ່ມໃຊ້ງານ
1. ຕິດຕັ້ງ Node.js (ມີແລ້ວໃນເຄື່ອງນີ້)
2. ກົດ `start.bat` ສອງເທື່ອ (ຫຼື `node server.js`) → ເປີດ http://localhost:3000
3. ຄອມ ແລະ ໂທລະສັບຂອງຜູ້ເຂົ້າຮ່ວມ ຕ້ອງຢູ່ Wi-Fi ດຽວກັນ ເພື່ອສະແກນ QR ລົງທະບຽນ
4. ຕ້ອງມີອິນເຕີເນັດ (ໂຫຼດ Tailwind / ຟອນ / QR library ຈາກ CDN)

## ໄຟລ໌
- `List.csv` – ລາຍຊື່ພະນັກງານ. ແກ້ໄຂໃນ Excel ແລ້ວ Save → ວົງລໍ້ອັບເດດເອງພາຍໃນ 3 ວິນາທີ
  (ຖ້າມີ `List.xlsx` ທີ່ໃໝ່ກວ່າ ຈະໃຊ້ໄຟລ໌ນັ້ນແທນ)
- `data/state.json` – ລາງວັນ, ຜົນການຈັບ, ຜູ້ລົງທະບຽນ (ລຶບໄຟລ໌ນີ້ = ເລີ່ມໃໝ່ທັງໝົດ)
- ຟອມລົງທະບຽນ: http://<IP ເຄື່ອງ>:3000/register

## ລາຍຊື່ພະນັກງານ
`List.csv` ບໍ່ໄດ້ຢູ່ໃນ GitHub (ຂໍ້ມູນສ່ວນຕົວ). ກັອບປີ້ `List.example.csv` ເປັນ `List.csv` ແລ້ວໃສ່ລາຍຊື່ແທ້.
