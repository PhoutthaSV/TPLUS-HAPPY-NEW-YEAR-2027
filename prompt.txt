ส้างเวบ Lucky draw wheel random ด้วย html + Tailwind CSS เอาโทนสี เหลือง ขาว 
-ของลางวัยสามาดเพี้มลบได้และใส่รุบพาบได้ ลางวันจะมีการกำนดจำนวน
- เวลากดหมุนวงล้อไห้สามาดเลือกลางวันก่อน สมหมุดว่าเลาเลือกลางวัน ทองคำ 5 ลางวัน วงล้อหมุน 5 วินาที ชะลอลงก่อนหยุด และทำไปตามจำนวนของลางวันจนคบ และ ลายชือ พะนฟกงานที่ random ได้ให้ลบออกจากวงล้อด้วย และ เก็บผนการได้รับลางวันไว้
- ไนวงล้อ ให้ดืงชือ พะนักงานจาก csv file เมื่อมีการอับเดดชือ พะนักงานที่ excel file ให้อับเดดวงล้อ auto
- และจะมีกอละนีพิเสด เป็นการแจกลางวันพิเสด จะเอาสะเพาะคนที่อยุในงาน คนที่สิดเข้าล้วมต้องสะแกน QR code และจะมี ฟอมกอกข้อมุน เพื่อเอามาใสในวงล้อ
